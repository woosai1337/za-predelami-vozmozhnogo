О проекте

Пояснительная записка к конкурсной работе: цель и задачи, аудитория, структура сайта, содержание разделов, перспективы развития и технические решения.

01 / Цель и задачи

Зачем сделана выставка

Цель: рассказать о вкладе женщин Беларуси в историю, науку, культуру и спорт через конкретные биографии и показать этот вклад в связи с Годом белорусской женщины.

Задачи:

  • собрать и проверить биографические данные о пятнадцати героинях;
  • представить материал в едином каталожном формате — с годами, сферой и источниками;
  • дать два способа навигации: по сферам деятельности и по хронологии;
  • обеспечить работу сайта на компьютере, планшете и телефоне;
  • указать источники и лицензии на все использованные фотографии.

Материал выставки — не рейтинг, а каталог: единый формат записи позволяет сравнивать биографии между собой.

03 / Структура и навигация

Как устроен сайт

Сайт состоит из трёх страниц, связанных единой навигацией в шапке и подвале. На каждой странице есть «хлебные крошки».

Главная
index.html
Каталог героинь
heroines.html
О проекте
about.html
Хроника
index.html#chronicle
Источники
about.html#sources

Навигация продублирована на трёх уровнях: основное меню, «хлебные крошки» и список разделов в подвале. На телефоне меню сворачивается в кнопку.

Из каталога любую запись можно открыть целиком — в отдельном окне поверх страницы, сохраняя контекст списка.

Ссылки на внешние источники открываются в новой вкладке и помечены как источники.

05 / Техника

Как сделан сайт

Разметка и стили
HTML5, CSS3
Скрипты
JavaScript без фреймворков
Трёхмерная графика
three.js (WebGL)
Шрифты
PT Serif, PT Sans, PT Mono
Размещение
GitHub Pages

Вёрстка адаптивная: три контрольные ширины — компьютер, планшет, телефон. Меню, таблицы и каталог перестраиваются под узкий экран.

Сайт работает в современных браузерах (Chrome, Safari, Firefox, Edge). Трёхмерная эмблема подключается только при поддержке WebGL: если технология недоступна, страница продолжает работать без неё.

Учтён режим «уменьшенное движение»: при включённой системной настройке анимации отключаются. Есть стили для печати, семантическая разметка, подписи к изображениям и навигация с клавиатуры.

06 / Перспективы

Что можно добавить дальше

  • расширить каталог до 30–40 биографий, включая современниц;
  • добавить белорусскоязычную версию выставки;
  • сделать отдельные страницы для каждой героини с полным списком источников;
  • подключить поиск по каталогу и по хронике.
  • добавить раздел с архивными фотографиями и документами;
  • сделать экспорт каталога в PDF для распечатки;
  • добавить версию для слабовидящих с увеличенным шрифтом;
  • записывать короткие аудиорассказы о героинях.
