# За пределами возможного

Виртуальная выставка о белорусских женщинах к Году белорусской женщины (2026).
Конкурсная работа: областной конкурс «Взгляд в будущее», номинация «Web-разработка».

## Страницы
- `index.html` — главная: обложка, о выставке, о годе, избранные записи, хроника, о конкурсе, источники
- `heroines.html` — каталог: указатель по годам, фильтр по сферам, 15 записей
- `about.html` — пояснительная записка: цель и задачи, аудитория, структура, содержание, перспективы, техника, источники

## Состав
- `css/style.css` — издательская система оформления (бумага, PT Serif / PT Sans / PT Mono)
- `js/data.js` — содержание выставки: героини, хроника, документы, источники
- `js/app.js` — сборка страниц, фильтр, каталожная запись
- `js/three-scene.js` + `js/vendor/three.min.js` — трёхмерная эмблема выставки (WebGL)
- `assets/photos/` — 15 портретов с указанием источника и лицензии

## Локальный запуск
```
python3 -m http.server 8000
```
