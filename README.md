# За пределами возможного

Веб-сайт к областному конкурсу «Взгляд в будущее» (номинация «Web-разработка»), посвящённый Году белорусской женщины — 2026.

## Структура
- `index.html` — единственная страница с разделами: О годе, Героини, Время, Наследие, О проекте
- `css/style.css` — оформление, анимации, адаптивность
- `js/data.js` — данные о героинях
- `js/app.js` — логика интерфейса (фильтры, модальные окна, анимации)
- `assets/favicon.svg` — иконка сайта

## Локальный запуск
Открыть `index.html` в браузере или запустить простой сервер:
```
python3 -m http.server 8000
```

## Публикация (GitHub Pages)
1. Создать репозиторий на GitHub.
2. Загрузить файлы в ветку `main`.
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `/(root)`.
