# За пределами возможного

> Виртуальная выставка к Году белорусской женщины. Знак выставки — трёхмерный государственный флаг Беларуси (WebGL).

Виртуальная выставка о белорусских женщинах к Году белорусской женщины (2026).
Конкурсная работа: областной конкурс «Взгляд в будущее», номинация «Web-разработка».

## Что на сайте
- Первый экран: 3D-знак выставки (орнаментальная розетка на WebGL) и главные цифры.
- «Четырнадцать биографий» — стена портретов с фильтром по сферам; каждая запись открывается целиком: фотография, сведения, значение, источник.
- «Хроника» — девять веков по датам (тёмный блок).
- «О годе» — документы и цифры Года белорусской женщины.
- «О конкурсной работе» и «Источники».

## Файлы
- `index.html` — страница выставки
- `css/style.css` — оформление: бумага, крупные портреты, один акцентный цвет
- `js/data.js` — содержание: героини, хроника, документы, источники
- `js/app.js` — стена портретов, фильтр, хроника, запись, навигация
- `js/three-scene.js` + `js/vendor/three.min.js` — 3D-знак (WebGL)
- `assets/photos/` — 14 портретов с указанием автора и лицензии

## Шрифты
Literata (заголовки) и Golos Text (текст) — обе с кириллицей, подключены с Google Fonts.

## Локальный запуск
```
python3 -m http.server 8000
```
